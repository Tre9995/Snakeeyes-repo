# Snakeeyes - Movies & TV Shows Addon

A comprehensive addon for accessing movies and TV shows from multiple streaming sources.

## 📺 Supported Providers

This addon includes the following streaming sources:

1. **CinemaCity** - Movies and TV Shows
2. **Dooflix** - Movies and TV Shows
3. **AllMovieland** - Movies and TV Shows
4. **PureStream** - Movies and TV Shows
5. **MovieBox (English)** - Movies and TV Shows
6. **Sinewix** - Movies and TV Shows
7. **NetMirror** - Movies and TV Shows

## 🚀 Installation

To use this addon, add the following manifest URL to your application:

```
https://raw.githubusercontent.com/Tre9995/Snakeeyes-repo/main/manifest.json
```

## 📋 Features

- Multiple streaming sources for maximum content availability
- Support for both movies and TV shows
- Easy provider switching
- Updated content catalog

## ⚙️ Configuration

The addon is configured via `manifest.json` which lists all available providers with their settings.
